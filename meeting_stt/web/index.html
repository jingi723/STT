🎙️ meeting_stt

로컬 ASR(Qwen3-ASR) · 화자분리(pyannote) · LLM-Wiki 회의록 대기

1. 입력 소스

웹미팅(Zoom/Meet 등)을 선택하면 그 앱 소리만 녹음됩니다. 들으면서 녹음돼요(라우팅 불필요).

스피커로 나가는 모든 소리를 통째로 녹음합니다. 앱을 고를 필요가 없어요. 최초 1회 '오디오 녹음' 권한 허용이 필요합니다.

2. 녹음

녹음 경과: 0:00:00 · 기록량: 0KB

⚠ 소리가 들어오지 않습니다 — 출력 소스/권한을 확인하세요

3. 저장된 녹음

서버를 다시 시작해도 outputs/recordings 세션을 불러와 재생·전사할 수 있습니다.

녹음 목록을 불러오는 중입니다.

4. 전사 옵션

녹음을 정지하거나 목록에서 선택하면 전사 대상에 올라갑니다. CPU 환경은 다소 시간이 걸립니다.

전사 결과 (화자 귀속)

아직 결과가 없습니다.
